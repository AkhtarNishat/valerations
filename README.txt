Keep index.html and the images folder together. Open index.html in a browser to preview.

To add more photos, copy them into images/ and add an image tag inside the correct product's <div class="media-grid">, using the exact filename.

Free hosting: create a free GitHub account, upload index.html and the entire images folder to a repository, then use Settings > Pages and deploy from the main branch/root folder. GitHub Pages will provide a public URL. Netlify (https://www.netlify.com/) is another free static hosting option. Custom domains usually cost extra.


ADMIN CONTENT EDITOR
Open admin.html to edit product titles, descriptions, highlights, captions and images. Save changes stores them in that browser. Export content creates a backup; Import content restores one. Preview website opens index.html. This static-site editor does not publish edits to other visitors/devices; shared live publishing requires a hosted CMS/backend.
